0. 最短でつながる学習順序

前半は「データ生成と確率」、後半は「標本から母集団へ」。回帰と分散分析は、最後に線形モデルとしてつなげます。

PHASE 1記述・収集データの形、相関、時系列、標本抽出、実験計画
PHASE 2確率モデル条件付き確率、期待値・分散、代表的な確率分布
PHASE 3推測統計標本分布 → 点・区間推定 → 仮説検定
PHASE 4線形モデル単回帰 → 重回帰 → 一元配置分散分析
一本の核標本統計量は標本ごとに揺れる。その「揺れの分布」が標本分布です。揺れの幅で区間を作れば推定、帰無仮説の下で今の値がどれほど珍しいかを測れば検定になります。

優先順位

  1. 最優先：正規・t・χ²・F分布の役割、区間推定、検定の選択、回帰・分散分析。
  2. 次点：離散分布の使い分け、標本抽出、時系列、カテゴリカルデータ。
  3. 確認中心：代表値・グラフなど既習範囲。ただし歪度、尖度、ローレンツ曲線、ジニ係数は漏らさない。
PHASE 1 · DESCRIBE

1. データを記述し、関係を見る

数値を出す前に、変数の型・分布の形・外れ値・層別の有無を確認します。

1変数

  • 質的変数：棒・円・度数表
  • 量的変数：幹葉図・ヒストグラム・累積度数
  • 形：対称／裾の方向／単峰・多峰／一様
  • 中心：平均・中央値・最頻値
  • 散らばり：不偏分散（n-1）、標準偏差、範囲、IQR、箱ひげ図

比較・形状

  • z得点：異なる尺度を平均0・標準偏差1へ
  • 変動係数 CV = 標準偏差 / 平均：単位の違う相対散らばり
  • 歪度：左右非対称、尖度：裾の重さ・ピーク形状
  • ローレンツ曲線とジニ係数：集中・不平等
  • 一様頻度からのずれ：Σ(観測-期待)²/期待
CVの落とし穴平均が0付近、負値が意味を持つ尺度、間隔尺度では解釈が不安定です。「0が絶対的な意味を持つ比率尺度」で使うのが基本。

2変数：共分散・相関・偏相関

標本相関係数r = Σ(xᵢ-x̄)(yᵢ-ȳ) / √{Σ(xᵢ-x̄)² Σ(yᵢ-ȳ)²}
  • 相関係数は直線的関係の強さ。非線形な強い関係でも r ≈ 0 はあり得ます。
  • 層別した散布図で群ごとの関係を確認。交絡変数が作るみかけの相関（擬相関）に注意。
  • 偏相関は第3変数の線形な影響を調整した相関。因果を証明する指標ではありません。
  • 相関行列では多変数の組合せを一覧化しますが、多数比較・外れ値・変数重複も点検します。

単回帰の入口

最小二乗推定ŷᵢ = b₀ + b₁xᵢ　　b₁ = Sxy / Sxx　　b₀ = ȳ - b₁x̄
変動の分解SST = SSR + SSE　　R² = SSR / SST = 1 - SSE / SST

残差 eᵢ = yᵢ - ŷᵢ を、予測値・説明変数・観測順に対して描きます。曲線、扇形、不連続、時系列パターンがあれば、線形性・等分散性・独立性を疑います。対数などの変数変換は、関係の線形化や分散安定化に使います。

R²の誤解高いR²は因果・予測の妥当性・モデル仮定の正しさを保証しません。説明変数を増やすと通常R²は下がらないため、重回帰では自由度調整済みR²も見ます。

PHASE 1 · COLLECT

2. どう集めたデータかを問う

統計手法が高度でも、データ取得の偏りは後から消せません。公的統計などのデータソース、定義、対象母集団、欠測も確認します。

区別目的・強み典型的な注意
全数調査対象集団をすべて測る非標本誤差、欠測、定義ずれは残る
標本調査一部から母集団を推測標本誤差と選択・無回答バイアスを分ける
観察研究現実の状態を観察交絡により、関連だけで因果を断定しにくい
実験研究処理を割り付けて効果を比較無作為割付・遵守・脱落・外的妥当性
無作為抽出と無作為割付は別物無作為抽出は「母集団へ一般化できるか」、無作為割付は「群間差を処理の因果効果とみなせるか」に主に関係します。

標本抽出法

系統抽出

無作為な開始点から一定間隔で選ぶ。名簿の周期性と抽出間隔が一致すると偏る。

層化抽出

母集団を層に分け、各層から抽出。層内が均質なら精度向上。全層を含む。

クラスター抽出

集団（学校・地域など）を選び、その中を調査。費用を抑えやすいが、集団内類似で誤差増大。

多段抽出

地域→世帯→個人のように段階的に選ぶ。実務的だが設計を考慮した推定が必要。

フィッシャーの3原則

  • 無作為化：処理割付をランダムにし、系統的な交絡を抑える。
  • 反復：各処理を複数単位に施し、偶然変動を評価する。
  • 局所管理（ブロック化）：似た実験単位をブロックにまとめ、不要な変動を除く。
30秒チェック：県内の全地域を人口層に分け、各層から住民を選ぶ方法は？
層化抽出。各層から標本を取る点が、選ばれたクラスター内を調べるクラスター抽出との違いです。
PHASE 2 · PROBABILITY

3. 確率を「更新」と「合成」で捉える

加法定理

P(A∪B)=P(A)+P(B)-P(A∩B)

「または」。排反なら共通部分は0。

乗法定理

P(A∩B)=P(A)P(B|A)

「かつ」。独立なら P(B|A)=P(B)。

ベイズの定理P(A|B) = P(B|A)P(A) / P(B)

事前確率 P(A) を、観測Bの起こりやすさ P(B|A) で更新して事後確率 P(A|B) を得ます。分母は起こり得る原因で全確率を取ります。

典型例：検査有病率1%、感度90%、偽陽性率5%なら、陽性者が有病である確率は 0.01×0.90 / (0.01×0.90 + 0.99×0.05) ≈ 15.4%。「感度90%だから陽性なら90%病気」は誤りです。

確率変数の期待値・分散

E(aX+b)=aE(X)+b　　Var(aX+b)=a²Var(X)
E(X+Y)=E(X)+E(Y)
Var(X+Y)=Var(X)+Var(Y)+2Cov(X,Y)

期待値の和に独立は不要。分散を単純に足せるのは共分散が0のときです。独立なら無相関ですが、無相関から独立は一般には言えません（2変量正規では例外的に言える）。

差の分散Var(X-Y)=Var(X)+Var(Y)-2Cov(X,Y)。独立なら「差」でも分散は足し算です。

PHASE 3 · SAMPLING DISTRIBUTIONS

5. 標本統計量にも分布がある

E(X̄)=μ　　Var(X̄)=σ²/n　　SE(X̄)=σ/√n

標本サイズを4倍にしても標準誤差は1/2。誤差を1/10にしたければ標本サイズは100倍必要です。

チェビシェフの不等式

分布形を問わず P(|X-μ|≥kσ)≤1/k²。粗いが普遍的。

大数の法則

nが増えると標本平均が母平均へ近づく。「値の収束」。

中心極限定理

条件下で標本平均の標準化が正規分布へ近づく。「分布形の収束」。

CLTの誤解nが大きいと元データ自体が正規になるのではなく、標本平均などの分布が正規に近づきます。強い歪み・外れ値・依存がある場合は「n≥30」の機械的適用を避けます。

4つの基準分布

分布中心となる統計量主な用途自由度
標準正規 Z(X̄-μ)/(σ/√n)母分散既知の平均、大標本の比率なし
t(X̄-μ)/(S/√n)正規母集団・母分散未知の平均n-1
χ²(n-1)S²/σ²正規母集団の母分散、度数の検定n-1 など
F(S₁²/σ₁²)/(S₂²/σ₂²)分散比、回帰・分散分析(n₁-1, n₂-1)

t・χ²・Fの正確な分布は正規母集団の仮定と結びつきます。tは左右対称で、自由度が増えると標準正規へ近づく。χ²とFは0以上で右に歪みます。

二項分布の正規近似と連続修正

X∼Bin(n,p) を Y∼N(np, np(1-p)) で近似するとき、離散値の境界を0.5だけずらします。

P(X≤k) ≈ P(Y≤k+0.5)　　P(X≥k) ≈ P(Y≥k-0.5)
上側確率点の読み方表が「P(T ≥ tα)=α」を載せるか、下側累積確率を載せるかを確認。両側5%なら片側2.5%ずつです。

PHASE 3 · HYPOTHESIS TESTING

7. 仮説検定：珍しさを基準に判断する

  1. 母数について H₀ と H₁ を、データを見る前に立てる。
  2. H₀の下で分布が分かる検定統計量を選ぶ。
  3. 観測値以上にH₁方向へ極端な確率＝p値を求める。
  4. p≤αならH₀を棄却。p>αなら「棄却できない」。
  5. 効果量・信頼区間・前提も併せて解釈する。

第1種の過誤

H₀が真なのに棄却。確率を有意水準α以下に制御。

第2種の過誤

H₁が真なのに棄却しない。確率β、検出力は1-β。

αを小さくすると、標本サイズなどを固定したままでは一般にβが増えます。検出力は効果が大きい、ばらつきが小さい、nが大きい、αが大きいほど高くなりやすい。

p値の誤解p値は「H₀が正しい確率」でも「偶然で結果が出た確率」でもありません。H₀を仮定したときに、観測値以上に極端な統計量が出る確率です。p>0.05は同等性の証明ではありません。

PHASE 3 · CATEGORICAL DATA

8. χ²検定：観測度数と期待度数を比べる

χ² = Σ (O-E)² / E

適合度検定

1つの質的変数の分布が、指定された比率に合うか。

自由度：k-1-m（カテゴリk、データから推定した母数m）

独立性検定

2つの質的変数が独立か。期待度数 Eij=(行合計×列合計)/n。

自由度：(r-1)(c-1)

χ²はずれの総量を測るため常に0以上。棄却域は上側です。独立性検定で棄却したら「関連がある」と言えますが、どのセルが寄与したかは標準化残差などで追加確認します。

小さい期待度数χ²近似が悪くなります。カテゴリ統合が科学的に妥当か、2×2ならFisherの正確確率検定など別手法が必要かを検討します。
PHASE 4 · LINEAR MODELS

9. 回帰分析：他の変数を固定した効果を読む

Yᵢ = β₀ + β₁Xᵢ₁ + … + βₚXᵢₚ + εᵢ

偏回帰係数βⱼは、他の説明変数を一定にしたとき、Xⱼが1単位増えることに伴うYの平均変化。係数のt検定は H₀:βⱼ=0、モデル全体のF検定は「切片以外の係数がすべて0」を検討します。

自由度調整済み決定係数R̄² = 1 - {SSE/(n-p-1)} / {SST/(n-1)}
確認点何を見るか問題があると
線形性残差 vs 予測値、部分残差曲線パターン、変換や項追加を検討
等分散性残差の広がり扇形、標準誤差・検定が不適切
独立性観測順残差、自己相関標準誤差を過小評価し得る
正規性残差の分布小標本でt/F推測に影響
多重共線性説明変数間相関、VIF係数が不安定、SE増大、符号変化

ダミー変数

kカテゴリなら通常k-1個の0/1変数を作り、除いたカテゴリを基準にします。切片は基準カテゴリ、ダミー係数は基準との差。切片とk個すべてのダミーを同時に入れると完全な多重共線性（ダミー変数トラップ）が起きます。

係数の有意性 ≠ 因果効果交絡、逆因果、選択バイアス、測定誤差があれば、調整済みでも因果とは限りません。また補外（観測範囲外の予測）は危険です。
出力表の読む順①モデル全体FとR̄² → ②係数・符号・単位 → ③標準誤差・t・p・信頼区間 → ④残差診断 → ⑤データ設計と解釈範囲。
PHASE 4 · ANOVA

10. 分散分析：3群以上の平均差を一度に検定

H₀: μ₁=…=μk。群間のばらつきが、群内の偶然変動に比べて十分大きいかをF比で測ります。

SST = SSB（群間） + SSE（群内）
F = MSB/MSE = {SSB/(k-1)} / {SSE/(N-k)}
変動源平方和自由度平均平方
群間（処理）SSB=Σnⱼ(x̄ⱼ-x̄)²k-1MSB=SSB/(k-1)
群内（誤差）SSE=ΣΣ(xᵢⱼ-x̄ⱼ)²N-kMSE=SSE/(N-k)
全体SST=ΣΣ(xᵢⱼ-x̄)²N-1-

前提：独立、各群が正規、等分散。Fが大きいほどH₀に反する。棄却できても「少なくとも1群の平均が異なる」までで、どの群かは多重比較が必要です。

回帰との統一一元配置ANOVAは、群をk-1個のダミー変数で表した回帰モデルと同じ線形モデルとして扱えます。ANOVAのF検定は、そのダミー係数がすべて0かを検定しています。
t検定を何度も行わないペアごとに5%検定を繰り返すと、少なくとも1回誤って棄却する確率が増えます。ANOVA後はTukey法など、家族内誤差率を考えた多重比較を使います。
FINAL REVIEW

11. 試験直前の判断テンプレート

問題を見たらこの順に書く

  1. データ型：量的／質的、1群／2群以上、独立／対応あり。
  2. 対象母数：平均、分散、比率、相関、回帰係数。
  3. 条件：正規性、母分散既知、等分散、標本サイズ、非復元。
  4. 統計量：Z、t、χ²、Fのどれか。自由度もセット。
  5. 方向：片側／両側、信頼係数とα。
  6. 結論：母集団・母数の言葉で、棄却／棄却できないを述べる。

頻出の混同 12

  • 標準偏差（データの散らばり）と標準誤差（推定量の散らばり）
  • 母分散σ²と不偏分散s²（n-1で割る）
  • 独立と排反
  • 無相関と独立
  • 大数の法則と中心極限定理
  • 推定量と推定値
  • 有意差と実質的に大きな差
  • 棄却できないこととH₀の証明
  • 無作為抽出と無作為割付
  • 独立2標本と対応のある標本
  • 検定の比率SE（H₀でプール）と区間のSE
  • 相関・回帰と因果

公式を覚える共通骨格

検定統計量 = (推定値 - H₀の値) / H₀下の標準誤差
信頼区間 = 推定値 ± 分位点 × 推定標準誤差

χ²とFは左右対称でないため「±」型にしないことが重要です。分散区間はχ²分位点で割るので上下が逆になります。

統計ソフトウェア出力で最低限読む場所

  • 変数・標本サイズ・欠測処理が想定どおりか。
  • 推定値、標準誤差、自由度、検定統計量、p値、信頼区間。
  • モデルならR²/調整済みR²、ANOVA表、残差・診断。
  • 数値を出すだけでなく、問題の文脈に戻して結論を書く。

PHASE 1 · DESCRIBE

1. データを記述し、関係を見る

数値を出す前に、変数の型・分布の形・外れ値・層別の有無を確認します。

まず尺度水準を確認する

変数の型が決まると、使ってよい統計量も自動的に決まります。「順序尺度に平均を当てる」といった典型的な誤りは、この確認だけで防げます。

尺度水準例意味を持つ操作使える代表値
名義尺度血液型、居住地、性別同じか違うかの区別だけ最頻値
順序尺度満足度5段階、成績A/B/C、震度大小の順序。間隔が等しい保証はない最頻値、中央値
間隔尺度摂氏温度、西暦、偏差値差に意味がある。0は便宜的な原点＋平均、標準偏差
比例尺度身長、金額、件数、時間比にも意味がある。0が「無い」を表す＋幾何平均、変動係数

摂氏20℃を10℃の「2倍暑い」と言えないのは、0℃が熱量ゼロを意味しないからです。変動係数や幾何平均が比例尺度でしか安定しないのも、同じ「原点が絶対か」という理由によります。名義・順序をまとめて質的（カテゴリ）変数、間隔・比例をまとめて量的変数と呼び、量的変数はさらに個数のような離散変数と、長さ・時間のような連続変数に分かれます。

分布の形をつかむ

  • 度数分布表・ヒストグラム：階級（ビン）に区切って度数を数えます。階級幅を変えると見え方が変わるので、山の数や裾の向きが「幅の取り方の産物」でないかを確かめます。
  • 幹葉図：もとの数値を残したまま分布の形も見える表示。データが少ないときに有効です。
  • 累積相対度数：「◯◯以下が全体の何割か」を読む曲線。中央値や四分位点はここから読み取れます。
  • 形の語彙：左右対称／右（正）に歪む／左（負）に歪む、単峰／多峰、一様。多峰なら性質の違う集団が混ざっている可能性があるので、層別を検討します。

中心を測る：平均・中央値・最頻値

算術平均x̄ = (1/n) Σᵢ₌₁ⁿ xᵢ

平均はすべての値を足して割るため、1つの極端な値に強く引っぱられます。中央値は順位だけで決まるので外れ値の影響を受けにくく（ロバスト）、最頻値は最も度数の多い値で、質的変数にも使えます。

  • 右に裾が長い分布（年収、待ち時間、滞在時間など）では、多くの場合 最頻値 < 中央値 < 平均 の順に並びます。平均が「典型的な人」を表さない代表例です。
  • 左右対称な単峰分布では3つはほぼ一致します。歪度の符号は、この3つの並び順とだいたい対応します。
  • 全データを a 倍して b を足すと、平均も a x̄ + b に移ります（線形変換に対する平均の性質）。

散らばりを測る：分散・標準偏差・四分位範囲

偏差平方和と標本分散（不偏分散）Sxx = Σ(xᵢ - x̄)²　　s² = Sxx / (n - 1)　　s = √(s²)

なぜ n ではなく n-1 で割るのか。偏差 xᵢ - x̄ は必ず Σ(xᵢ - x̄) = 0 を満たすので、n個の偏差のうち自由に動けるのは n-1 個だけです。この個数を自由度と呼びます。さらに偏差平方和は「x̄ のまわりで測ったときに最小になる量」なので、未知の母平均 μ のまわりで測った平方和より必ず小さくなり、n で割ると母分散 σ² を系統的に小さく見積もってしまいます。n-1 で割ると E(s²) = σ² がちょうど成立します（不偏性）。

不偏なのは分散までs² は σ² の不偏推定量ですが、その平方根 s は σ の不偏推定量ではありません。平方根が非線形な変換のため E(√(s²)) ≠ √(E(s²)) となるからです。試験では「不偏分散は n-1 で割る／標準偏差はその平方根」まで押さえれば十分です。
手計算用の展開形Σ(xᵢ - x̄)² = Σxᵢ² - n x̄²

標準偏差 s はもとのデータと同じ単位を持つので解釈しやすく、分散 s² は単位が2乗になる代わりに足し算ができます（後の分散の加法性）。用途で使い分けます。

四分位数は、小さい順に並べたデータを4等分する位置の値です。Q1（下側25%点）、Q2（中央値）、Q3（上側25%点）とし、四分位範囲 IQR = Q3 - Q1 は中央50%が占める幅を表します。箱ひげ図の箱がこのIQR、箱の中の線が中央値で、ひげは慣習的に「箱から 1.5×IQR 以内に収まる最も外側のデータ」まで伸ばし、それを超える点を外れ値として個別に描きます。範囲（最大-最小）は外れ値1点で決まってしまうため、散らばりの指標としては不安定です。

単位をそろえる：標準化と変動係数

z得点（標準化）zᵢ = (xᵢ - x̄) / s　　→　平均0、標準偏差1

「平均から標準偏差いくつぶん離れているか」に変換する操作です。単位が消えるので、英語と数学のように尺度の違う得点でも比較できます。偏差値は z を 50 + 10z と置き直したもの。標準化は位置と尺度を変えるだけなので、分布の形（歪み方や裾の重さ）は変わりません。「z = 2 なら上位2.3%」という換算が使えるのは、もとの分布が正規分布に近いときだけです。

変動係数CV = s / x̄

標準偏差を平均で割り、「平均に対して何割ばらつくか」を見る相対指標です。年収（円）と体重（kg）のように単位も水準も違う量のばらつきを比べたいときに使います。

CVの落とし穴平均が0付近、負値が意味を持つ尺度、間隔尺度では解釈が不安定です。「0が絶対的な意味を持つ比率尺度」で使うのが基本。

形を数値にする：歪度と尖度

標本歪度・標本尖度（代表的な定義）歪度 = (1/n) Σ ((xᵢ - x̄)/s)³　　尖度 = (1/n) Σ ((xᵢ - x̄)/s)⁴

どちらも標準化した偏差の累乗の平均です。ポイントは指数が奇数か偶数かにあります。

  • 歪度（3乗＝奇数）：符号が残るので、左右どちら側に大きな偏差が偏っているかを測れます。正なら右に裾が長い（少数の大きな値が引っぱる／年収分布が典型）、負なら左に裾が長い。左右対称な分布では0です。
  • 尖度（4乗＝偶数）：符号が消え、大きな偏差だけが極端に強調されます。したがって尖度が測るのは主に裾の重さ（外れ値の出やすさ）で、「山の尖り」は副次的な見え方にすぎません。正規分布の尖度は3で、3 を引いた超過尖度を使って「0なら正規並み、正なら裾が重い」と読む流儀もあります。定義によって3を引くかどうかが違うので、問題文の基準を確認します。

集中度：ローレンツ曲線とジニ係数

所得などを小さい順に並べ、横軸に世帯の累積相対度数、縦軸に所得の累積相対度数を取った曲線がローレンツ曲線です。「下位40%の世帯が全所得の何%を得ているか」を読む図で、完全に平等なら45度線（均等分布線）に一致し、不平等が強いほど右下にたわみます。

ジニ係数G = 2 × (均等分布線とローレンツ曲線が挟む面積)　　0 ≤ G ≤ 1

挟まれた面積（三日月形の部分）を、三角形の面積 1/2 で割ったもの、と考えても同じです。G = 0 が完全平等、1に近いほど一部への集中が強いことを意味します。ただし曲線が交差する2集団は、ジニ係数だけでは優劣を決められません。面積という1つの数値に潰す過程で、どの層で差がついているかの情報が失われるためです。

度数分布の「一様からのずれ」を測る Σ(観測度数 - 期待度数)² / 期待度数 は、そのまま第8章の χ² 適合度検定の統計量になります。記述の段階で見たずれを、確率的に評価し直すのが検定です。

2変数の関係：共分散から相関係数へ

2つの量が「一緒に動くか」を測る出発点は共分散です。x が平均より大きいとき y も平均より大きければ、偏差の積 (xᵢ-x̄)(yᵢ-ȳ) は正になります。これを平均すれば、同じ向きに動く傾向が正、逆向きなら負として表せます。

共分散Sxy = Σ(xᵢ-x̄)(yᵢ-ȳ)　　sxy = Sxy / (n-1)

ただし共分散には単位が残ります（身長cm×体重kgなら「cm·kg」）。単位を変えるだけで数値が変わってしまい、強さの比較ができません。そこで、それぞれの標準偏差で割って無次元化したものが相関係数です。

標本相関係数r = Sxy / √{Sxx · Syy} = sxy / (sx sy)

これは「x と y をそれぞれ標準化してから共分散を取った値」と同じです。標準化した2変数の共分散は必ず -1 と +1 の間に収まる（コーシー・シュワルツの不等式）ため、-1 ≤ r ≤ 1 が保証されます。r = ±1 は全点が完全に1本の直線上に乗る場合で、符号は直線の傾きの向きを表します。

r の値散布図の見え方読み方の注意
r ≈ +1右上がりの細い帯「強い」だけで、傾きの大きさは分からない
r ≈ 0丸い雲、あるいはU字・放物線「関係がない」ではなく「直線的関係がない」
r ≈ -1右下がりの細い帯強さは |r| で見る。符号は向きだけ
  • 相関係数は直線関係の強さしか測りません。y = x² のように強い関係があっても、対称な範囲で観測すれば r ≈ 0 になります。必ず散布図を先に見ます。
  • 外れ値1点で大きく動きます。共分散が偏差の積の和である以上、極端な点の寄与が支配的になり得ます。
  • 単位変換では変わりません。cm→m のような正の線形変換に対して r は不変です（共分散は変わります）。
  • 層別を忘れない。群ごとに見ると正の相関なのに、群をまとめると負に見える（またはその逆）ことがあります。これがシンプソンのパラドックスで、原因は群と変数の両方に効く交絡変数です。
擬相関（みかけの相関）アイスの売上と水難事故件数はよく相関しますが、共通原因は「気温」です。第3の変数 z が x と y の双方を動かしているとき、x と y の間に因果がなくても相関は現れます。相関は因果の必要条件のひとつにすぎません。

偏相関係数：第3の変数を差し引く

偏相関係数rxy·z = (rxy - rxz ryz) / √{(1 - rxz²)(1 - ryz²)}

意味は「x から z の線形な影響を取り除いた残り」と「y から z の線形な影響を取り除いた残り」の相関です。上の例で z = 気温 を調整すると rxy·z は0に近づき、見かけの相関が z によるものだったと分かります。ただし調整できるのは測定済みの変数の、線形な影響だけなので、これでも因果の証明にはなりません。

3変数以上を一覧するときは相関行列を作りますが、対角は必ず1、上三角と下三角は対称です。多数の組を同時に眺めると偶然大きい値が紛れ込むこと（多重比較の問題）、変数が実質的に重複していること、外れ値の影響も併せて点検します。

単回帰：関係に1本の直線を当てる

相関が「対等な2変数の連動」を測るのに対し、回帰は説明変数 x から目的変数 y を予測する非対称な当てはめです。当てはめの基準は、実測値と予測値のずれ（残差）の二乗和を最小にすること、すなわち最小二乗法です。

最小化する量Q(b₀, b₁) = Σ(yᵢ - b₀ - b₁xᵢ)² → 最小

Q を b₀、b₁ それぞれで偏微分して0と置くと（正規方程式）、次の解が得られます。

最小二乗推定量ŷᵢ = b₀ + b₁xᵢ　　b₁ = Sxy / Sxx　　b₀ = ȳ - b₁x̄

b₀ の式を見ると、回帰直線は必ず点 (x̄, ȳ) を通ることが分かります。また b₁ は相関係数と次の関係にあります。

傾きと相関係数b₁ = r · (sy / sx)

つまり傾きは「相関の強さ」に「y と x のばらつきの比」を掛けたもの。r が同じでも傾きは単位次第で変わるし、逆に傾きが大きいからといって当てはまりが良いとは限りません。なお b₁ の解釈は「x が1単位増えたときの y の平均的な変化」であって、「x を1単位増やせば y がそれだけ変わる」という介入の主張ではありません。

変動の分解と決定係数

平方和の分解SST = Σ(yᵢ-ȳ)²　　SSR = Σ(ŷᵢ-ȳ)²　　SSE = Σ(yᵢ-ŷᵢ)²　　SST = SSR + SSE

y のばらつき全体（SST）を、直線で説明できた分（SSR：回帰による変動）と説明できなかった分（SSE：残差変動）に分けています。その比率が決定係数です。

決定係数R² = SSR / SST = 1 - SSE / SST　　（0 ≤ R² ≤ 1）

「y の変動のうち何割を x で説明できたか」を表します。単回帰では R² = r² が成り立つため、r = 0.7 なら説明できたのは49%にとどまる、という読み方ができます。

残差を必ず見る

残差 eᵢ = yᵢ - ŷᵢ は、モデルが取りこぼした情報です。最小二乗法の性質から Σeᵢ = 0、また Σxᵢeᵢ = 0 となるので、残差に「まだ構造が残っている」なら、それはモデルの不足を意味します。

  • 残差 vs 予測値に曲線パターン → 直線では足りない。二次項や対数変換を検討。
  • 扇形に広がる → 等分散性の破れ（不均一分散）。y の対数変換などを検討。
  • 観測順に並べて波打つ → 独立性の破れ（系列相関）。時系列モデルを検討。
  • 1点だけ大きく外れる → 外れ値・影響点。x が端にある点は傾きを強く動かします（てこ比）。

対数変換は、右に歪んだ変数を対称に近づけ、分散を安定させ、かけ算の関係（y = a·xb）を log y = log a + b log x という足し算の関係に直す、という3つの働きをまとめて担います。

R²の誤解高いR²は因果・予測の妥当性・モデル仮定の正しさを保証しません。説明変数を増やすと通常R²は下がらないため、重回帰では自由度調整済みR²も見ます。

時系列：順番を捨てない

時系列データは「同じ対象を時間順に測ったもの」で、観測どうしが独立ではありません。並べ替えると情報が失われるため、横断データ用の道具をそのまま使えない点が最大の注意です。まずトレンド（長期傾向）・季節変動（周期）・不規則変動に分けて眺めます。

変化率と指数化

成長率（変化率）成長率 = (当期の値 / 前期の値) - 1　　指数 = (当期の値 / 基準時点の値) × 100

指数化は、単位も水準も違う系列を「基準時点＝100」にそろえて比較するための操作です。基準時点を変えれば見え方も変わるので、どこを100にしたかは必ず明示します。

なぜ平均成長率は幾何平均なのか

成長率は毎期掛け算で積み上がります。n期後の値は 初期値 × (1+r₁)(1+r₂)…(1+rₙ) なので、「毎期これで置き換えても同じ最終値になる率」を求めるには、算術平均ではなく積のn乗根を取る必要があります。

平均成長率（幾何平均）1 + r̄ = {(1+r₁)(1+r₂)…(1+rₙ)}1/n = (最終値 / 初期値)1/n
数値で確認1年目 +100%（2倍）、2年目 -50%（0.5倍）なら、資産は元に戻るので平均成長率は0%であるべきです。算術平均は (100% - 50%)/2 = +25% と誤り、幾何平均は √(2 × 0.5) - 1 = 0% と正しく答えます。比率・倍率の平均は幾何平均、というのはこの構造から来ています。

系列の依存構造：自己相関と移動平均

ラグk の自己相関係数rk = Σt=k+1n(xt-x̄)(xt-k-x̄) / Σt=1n(xt-x̄)²

これは「系列とそれを k 期ずらした自分自身との相関」です。r₁ が大きければ前期の値が今期を予測でき、月次データで r₁₂ が大きければ1年周期の季節性があると読めます。ラグごとの rk を棒グラフにしたものがコレログラムで、緩やかに減衰しない形はトレンドの存在を示唆します。

中心化移動平均（項数 m の例）MAt = (xt-1 + xt + xt+1) / 3　　（m = 3 の場合）

交絡とは何か

交絡変数とは、「原因と考えている変数」と「結果」の両方に関係し、両者の見かけの関連を作り出す第3の変数です。たとえば「コーヒーを飲む人ほど肺がんが多い」という観察結果があっても、喫煙者ほどコーヒーをよく飲むなら、喫煙が交絡変数です。交絡への対処は大きく3つ。設計段階で無作為割付やブロック化により潰す、解析段階で層別や重回帰により調整する、あるいは限定して同質な対象だけを集める。ただし解析での調整は「測って記録した変数」にしか効かないため、未測定の交絡は残ります。実験研究が強いのは、無作為割付が未知の交絡変数まで平均的に均すからです。

標本抽出法

基本は単純無作為抽出で、母集団の各要素が等しい確率で選ばれます。実務ではコストや名簿の都合から、次の方法が使われます。いずれも「無作為性を保ったまま、コストや精度を調整する」工夫です。

系統抽出（等間隔抽出）

名簿の先頭から無作為に開始点を選び、あとは一定間隔 k = N/n ごとに抽出します。実施が簡単で、名簿に順序情報（例：成績順）があれば層化に近い効果も得られます。危険なのは名簿の周期性と抽出間隔が一致する場合で、たとえば「5人1組の名簿から5人おき」に取ると、常に同じ役割の人ばかりが選ばれて大きく偏ります。

層化抽出

母集団を性別・年齢・地域などの層に分け、各層から抽出して合成します。全層が必ず標本に含まれるため代表性が確保され、層内が均質で層間の差が大きいほど推定精度が上がります（層間の変動を誤差から取り除けるため）。各層の大きさに比例して配分するのが比例配分です。

クラスター（集落）抽出

学校・町丁目などの集団そのものを無作為に選び、選ばれた集団は原則全員を調査します。移動コストや名簿整備の手間を大幅に減らせる一方、同じ集団内の個人は似ていることが多く、実質的な情報量が減って同じnでも標本誤差は大きくなりがちです。層化と逆で、集落内が多様であるほど良い点に注意。

多段抽出

市区町村 → 世帯 → 個人のように段階的に抽出します。全国調査で現実的に使われますが、段階ごとに抽出確率が異なるため、推定の際は抽出確率の逆数による重み付けなど、設計を反映した計算が必要です。

層化とクラスターの見分け「すべてのグループから少しずつ」なら層化、「いくつかのグループを丸ごと」ならクラスター抽出です。目的も逆で、層化は精度を上げるため、クラスターはコストを下げるために使います。

実験計画：フィッシャーの3原則

実験の目的は、処理の効果を偶然変動と区別できる形で取り出すことです。3原則はそれぞれ別の役割を担います。

  • 無作為化（randomization）：どの実験単位にどの処理を与えるかをくじ引きで決めます。これにより、年齢・体質・順序といった測っていない要因まで含めて群間で平均的に均され、群の差を処理の効果とみなす根拠が生まれます。交絡への最強の対策です。
  • 反復（replication）：同じ処理を複数の実験単位に施します。反復がなければ「差」が偶然のばらつきの範囲内かを判断する物差し（誤差分散）が作れません。分散分析の群内平方和 SSE は、まさにこの反復から誤差の大きさを見積もっています。
  • 局所管理（local control／ブロック化）：似た性質の実験単位をブロックにまとめ、ブロック内で処理を無作為に割り付けます。畑の肥沃度や測定日といった既知で邪魔な変動をブロック要因として分離することで、誤差分散が小さくなり検出力が上がります。
3原則の分業無作為化は「未知の要因」を平均的に均し、局所管理は「既知の要因」を明示的に取り除き、反復は「偶然の大きさ」を測る物差しを作ります。同じ交絡対策でも狙う相手が違います。

関連して、対照群（比較の基準となる群）を置くことも不可欠です。処理群だけを測っても「処理をしなかったらどうだったか」が分からず、時間経過やプラセボ効果と区別できません。

PHASE 2 · PROBABILITY

3. 確率を「更新」と「合成」で捉える

推測統計は「母集団を仮定したとき、こういうデータが出る確率はどれくらいか」を計算する営みです。その計算道具がこの章です。

用語の土台

  • 試行：結果が偶然で決まる観測や実験。標本空間 Ω：起こり得る結果すべての集合。事象：そのうち注目する部分集合。
  • 確率の性質：0 ≤ P(A) ≤ 1、P(Ω) = 1、排反な事象では確率が足せる。余事象は P(Ac) = 1 - P(A)。
  • 排反（互いに素）：同時には起こらない（A ∩ B = ∅）。独立：一方の結果が他方の起こりやすさを変えない。この2つは全く別の概念です。
排反 ≠ 独立「1回のサイコロで1の目」と「2の目」は排反ですが、独立ではありません。1が出たと分かれば2の確率は0に変わるからです。むしろ確率が正の2事象が排反なら、必ず従属です。排反は集合の話、独立は確率の話と覚えます。

加法定理と乗法定理

加法定理

P(A∪B)=P(A)+P(B)-P(A∩B)

「または」。排反なら共通部分は0。

乗法定理

P(A∩B)=P(A)P(B|A)

「かつ」。独立なら P(B|A)=P(B)。

加法定理は、A と B を単純に足すと重なりを二重に数えてしまうので、共通部分を引き戻している式です。乗法定理は条件付き確率の定義そのもので、次のように書けます。

条件付き確率の定義P(B|A) = P(A∩B) / P(A)　　（P(A) > 0）

意味は「標本空間を A の中だけに縮めて、その中で B が占める割合を測り直す」こと。分母が P(A) なのは、縮めた世界での全体を1に直す（規格化する）ためです。ここから独立の定義も導けます。P(B|A) = P(B) が成り立つとき、乗法定理は P(A∩B) = P(A)P(B) という掛け算の形になります。

全確率の定理とベイズの定理

原因が A₁, A₂, …, Ak に分かれている（排反で、全体を覆う）とき、結果 B が起こる確率は、原因ごとの経路をすべて足したものです。

全確率の定理P(B) = Σⱼ P(Aⱼ) P(B|Aⱼ)
ベイズの定理P(A|B) = P(B|A)P(A) / P(B) = P(B|A)P(A) / Σⱼ P(Aⱼ)P(B|Aⱼ)

導出は単純で、乗法定理を2通りに書いた P(A∩B) = P(A)P(B|A) = P(B)P(A|B) を P(A|B) について解くだけです。しかし意味は大きく、「原因 → 結果」の確率を「結果 → 原因」の確率にひっくり返す操作になっています。P(A) を事前確率（データを見る前の信念）、P(B|A) を尤度（その原因ならこの結果がどれだけ出やすいか）、P(A|B) を事後確率と呼びます。

逆確率の混同P(B|A) と P(A|B) は別物です。「病気なら陽性になる確率（感度）」と「陽性なら病気である確率」を同一視するのが最もよくある誤りで、両者は事前確率 P(A) の大小でいくらでもずれます。
典型例：検査の陽性的中率有病率 P(病気) = 1%、感度 P(陽性|病気) = 90%、偽陽性率 P(陽性|健康) = 5% とします。
分子（病気かつ陽性）＝ 0.01 × 0.90 = 0.009。
分母（陽性全体）＝ 0.01 × 0.90 + 0.99 × 0.05 = 0.009 + 0.0495 = 0.0585。
よって P(病気|陽性) = 0.009 / 0.0585 ≈ 15.4%。
直感より低いのは、健康な人が圧倒的に多いため、偽陽性の絶対数（0.0495）が真陽性（0.009）を大きく上回るからです。有病率が高い集団で同じ検査を使えば的中率は上がる、という点も併せて理解しておきます。

確率変数・期待値・分散

確率変数とは、試行の結果に数値を割り当てた変数です（サイコロの目、身長など）。取りうる値が飛び飛びなら離散型、連続的なら連続型で、前者は確率質量関数 P(X = x)、後者は確率密度関数 f(x) で分布を表します。

期待値（平均）離散型：E(X) = Σ x P(X = x)　　連続型：E(X) = ∫ x f(x) dx

期待値は「値 × その確率」の総和、つまり確率で重み付けした平均です。長期的に試行を繰り返したときの平均値の落ち着き先であり、1回の試行で実際に出る値ではありません（サイコロの期待値3.5はどの目にもない）。

分散Var(X) = E[(X - μ)²] = E(X²) - {E(X)}²　　（μ = E(X)）

右側の展開形は計算に便利です。「2乗の平均 - 平均の2乗」と覚えます。標準偏差は SD(X) = √Var(X) で、X と同じ単位に戻ります。

線形変換の公式

E(aX + b) = aE(X) + b　　Var(aX + b) = a²Var(X)　　SD(aX + b) = |a|SD(X)

平均は平行移動 b の影響を受けますが、分散は受けません。散らばりは「中心からのずれ」なので、全体を同じだけずらしても変わらないからです。一方 a 倍すると、ずれも a 倍され、2乗して a² 倍になります。この式から、標準化 Z = (X-μ)/σ が平均0・分散1になることも直接確かめられます。

和の期待値・分散と共分散

E(X + Y) = E(X) + E(Y)　　（常に成立。独立性は不要）
Cov(X, Y) = E[(X-μX)(Y-μY)] = E(XY) - E(X)E(Y)
Var(X ± Y) = Var(X) + Var(Y) ± 2Cov(X, Y)

期待値の加法性は無条件で成り立つ強力な性質です。一方分散を単純に足せるのは Cov(X,Y) = 0 のときだけ。共分散は「2つが同じ向きにずれる傾向」を表し、正なら合計のばらつきは各々の和より大きくなります。確率変数の相関係数は ρ = Cov(X,Y) / {SD(X)SD(Y)} で定義され、-1 ≤ ρ ≤ 1 です。

差でも分散は足し算独立なら Cov = 0 なので Var(X - Y) = Var(X) + Var(Y) です。引き算なのに足すのは、X と Y のどちらのばらつきも「差」の不確かさを増やすからです。2標本の平均差の標準誤差が √(σ₁²/n₁ + σ₂²/n₂) と和の形になるのは、この性質が根拠になっています。
独立 ⇒ 無相関、逆は不成立独立なら必ず Cov = 0 ですが、Cov = 0 でも独立とは限りません。たとえば X が -1, 0, 1 を等確率で取り Y = X² とすると、完全な従属関係があるのに共分散は0です。共分散が捉えるのは直線的な連動だけだからです。例外的に、2変量正規分布に従う場合に限り無相関と独立が同値になります。

Var(2X - Y) = 2²Var(X) + (-1)²Var(Y) = 4×4 + 9 = 25。係数は2乗して掛かり、符号は分散には影響しません。

主要分布を式で理解する

ベルヌーイ分布と二項分布

二項分布 Bin(n, p)P(X = k) = nCk pk(1-p)n-k　　(k = 0, 1, …, n)

式の3つの部分が、それぞれ別の役割を持ちます。pk は「成功が k 回起きる確率」、(1-p)n-k は「残りが失敗である確率」、そして nCk は「n回のうちどの回が成功だったか」の並び方の数です。順序を区別しないので組合せを掛けます。

二項分布は独立なベルヌーイ試行の和 X = X₁ + … + Xₙ なので、期待値と分散は加法性から即座に出ます。1回あたり E(Xᵢ) = p、Var(Xᵢ) = E(Xᵢ²) - p² = p - p² = p(1-p) なので、n倍して E(X) = np、Var(X) = np(1-p)。分散は p = 0.5 のとき最大になり、p が0や1に近いほど小さくなります（結果がほぼ決まっているため）。

ポアソン分布

ポアソン分布 Po(λ)P(X = k) = e-λ λk / k!　　(k = 0, 1, 2, …)

「一定の時間・面積・区間のなかで、めったに起きない事象が何回起きるか」を表します。1時間の来客数、1ページの誤植数、単位面積あたりの事故件数など。二項分布で n を大きく、p を小さくし、np = λ を一定に保った極限がこの分布です（少数の法則）。そのためE(X) = Var(X) = λ となります。二項の分散 np(1-p) で p → 0 とすれば np = λ に一致する、と見れば納得できます。

実データで分散が平均より明らかに大きい（過分散）なら、事象が独立でなく群れて起きている疑いがあります。またポアソン分布には再生性があり、独立な Po(λ₁) と Po(λ₂) の和は Po(λ₁+λ₂) です。「1時間あたり3件なら2時間あたり6件」と λ を時間に比例させて読み替えられるのは、この性質によります。

幾何分布と負の二項分布

幾何分布P(X = k) = (1-p)k-1 p　　（k回目で初めて成功）
負の二項分布P(X = k) = k-1Cr-1 pr(1-p)k-r　　（k回目でちょうどr回目の成功）

二項分布が「試行回数 n を固定して成功回数を数える」のに対し、こちらは成功回数を固定して試行回数を数えるという、役割を入れ替えた分布です。負の二項の組合せが k-1Cr-1 なのは、最後の k 回目が成功と決まっているため、残り r-1 回の成功を先頭 k-1 回のどこに置くかだけを数えるからです（r = 1 とすれば幾何分布に一致）。

幾何分布の平均が 1/p であることは直感的です。成功率が 1/6 なら平均6回かかる、という関係になります。

無記憶性幾何分布は P(X > s+t | X > s) = P(X > t) を満たします。「すでに10回失敗した」という情報は、その先の必要回数の分布を一切変えません。コインに記憶はなく、「そろそろ当たるはず」は誤りです（ギャンブラーの誤謬）。連続版の指数分布も同じ性質を持ち、離散・連続それぞれで無記憶性を持つ分布はこの2つだけです。

超幾何分布

超幾何分布 HG(N, K, n)P(X = k) = KCk · N-KCn-k / NCn

N個中K個が「当たり」の有限集団から、戻さずに n 個取ったときの当たり数です。分母は取り方の総数、分子は「当たりから k 個、はずれから n-k 個」選ぶ場合の数。1個取るごとに残りの構成が変わるため試行は独立ではなく、二項分布は使えません。

分散と有限母集団修正Var(X) = n·p(1-p)·(N-n)/(N-1)　　（p = K/N）

平均は二項と同じ np ですが、分散には (N-n)/(N-1) という因子が掛かって小さくなります。全部取り尽くせば（n = N）分散は0、つまり結果が確定するからです。逆に N が n に比べて十分大きければこの因子は1に近づき、超幾何分布は二項分布で近似できます（目安として抽出率 n/N が5%程度以下）。この因子は第6章の「有限母集団補正」と同じものです。

一様分布と指数分布

連続一様分布 U(a, b)f(x) = 1/(b-a)　(a ≤ x ≤ b)　　E(X) = (a+b)/2　　Var(X) = (b-a)²/12

密度が区間内で一定なので、確率は長さの比で計算できます。P(c ≤ X ≤ d) = (d-c)/(b-a)。

指数分布 Exp(λ)f(x) = λe-λx　(x ≥ 0)　　P(X > x) = e-λx　　E(X) = 1/λ　　Var(X) = 1/λ²

ポアソン過程で「次の事象が起きるまでの待ち時間」を表します。ポアソン分布と指数分布は同じ現象の裏表で、1時間あたり平均3件（λ = 3）なら、次の到着までの平均待ち時間は 1/3 時間 = 20分。P(X > x) = e-λx は「時間 x のあいだに1件も起きない確率」＝ポアソン分布で k = 0 とした e-λx そのものです。指数分布も無記憶性を持つため、「もう30分待った」ことは残り待ち時間の分布を変えません。

正規分布

正規分布 N(μ, σ²)f(x) = 1/(σ√(2π)) · exp{ -(x-μ)² / (2σ²) }

式を丸暗記する必要はありませんが、構造は読めます。指数の中身が -(x-μ)²/(2σ²) なので、平均 μ を中心に左右対称で、離れるほど二乗の速さで密度が落ちます。σ は幅を決める尺度母数で、前の 1/(σ√(2π)) は全体の面積を1にそろえる係数です。多数の小さな独立要因が足し合わさってできる量が正規分布に近づく（中心極限定理）ため、測定誤差や身長などに現れます。

  • 68-95-99.7の法則：μ±σ に約68%、μ±2σ に約95%、μ±3σ に約99.7%。厳密に95%なら係数は1.96です。
  • 再生性：独立な正規変数の和も正規分布。X ∼ N(μ₁,σ₁²)、Y ∼ N(μ₂,σ₂²) が独立なら X+Y ∼ N(μ₁+μ₂, σ₁²+σ₂²)、X-Y ∼ N(μ₁-μ₂, σ₁²+σ₂²)。2標本問題の土台です。
  • 線形変換で正規のまま：aX+b も正規分布に従うので、標準化して数表を1つだけ持てば済みます。

標準化と2変量正規分布

Z = (X - μ)/σ ∼ N(0, 1)

どんな正規分布も、この1本の式で標準正規分布に移せます。μ を引いて中心を0に、σ で割って幅を1にそろえる操作です。「x 以下の確率」を求めたければ、境界を同じ式で z に直してから標準正規表を引きます。P(X ≤ x) = P(Z ≤ (x-μ)/σ)。表が下側確率か上側確率か、対称性 P(Z ≤ -z) = 1 - P(Z ≤ z) を使うかは、毎回確認します。

2変量正規分布は、2つの変数の同時分布が μ₁, μ₂, σ₁, σ₂, ρ の5つの母数で決まる分布です。等高線（同じ密度の点をつないだ線）は楕円になり、ρ = 0 なら軸に平行な楕円（円に近い）、|ρ| が大きいほど細長く傾きます。重要な性質は2つ。

  • 周辺分布も条件付き分布も正規：x を固定したときの y の分布も正規で、その平均は x の1次式になります。これが回帰直線の理論的な裏付けです。
  • ρ = 0 と独立が同値：ここが一般の分布と決定的に違う点です。ただし「x も y もそれぞれ正規」というだけでは足りず、同時に2変量正規であることが条件です。

PHASE 3 · SAMPLING DISTRIBUTIONS

5. 標本統計量にも分布がある

推測統計の心臓部です。「標本平均は標本ごとに違う値になる。その違い方には法則がある」——この一点を押さえると、推定も検定も同じ道具で片づきます。

標本分布とは何か

母集団から大きさ n の標本を取り、平均 x̄ を計算します。もう一度取り直せば、違う x̄ が出ます。これを無限に繰り返したときにできる「x̄ という統計量そのものの分布」が標本分布です。私たちが手にしているのはその中のたった1つの実現値であり、「自分の x̄ が、あり得た値の中でどのあたりにいるか」を知るために標本分布が要ります。

標本平均の期待値・分散・標準誤差E(X̄) = μ　　Var(X̄) = σ²/n　　SE(X̄) = σ/√n

導出は前章の公式だけで済みます。X̄ = (X₁+…+Xₙ)/n について、期待値の加法性から E(X̄) = (nμ)/n = μ。分散は、独立なので単純に足せて Var(ΣXᵢ) = nσ²、これに 1/n を掛けると係数は2乗されるので Var(X̄) = nσ²/n² = σ²/n となります。

  • E(X̄) = μ：標本平均は母平均のまわりに散らばる（偏りがない＝不偏性）。
  • SE = σ/√n：散らばりの大きさは n の平方根に反比例して縮む。標本サイズを4倍にしても標準誤差は半分。誤差を1/10にしたければ n は100倍必要です。調査の精度改善が高くつくのはこのためです。
標準偏差と標準誤差σ（標準偏差）は「個々のデータのばらつき」、SE（標準誤差）は「推定量のばらつき」です。σ は n を増やしても変わりませんが、SE は小さくなります。答案で「標本平均の標準偏差」と書くべき場面は、実質的に標準誤差のことを指しています。

n が大きいと何が起きるか：3つの定理

チェビシェフの不等式

P(|X - μ| ≥ kσ) ≤ 1/k²　　(k > 1)

分布の形を一切仮定せずに使える不等式です。どんな分布でも「平均から2σ以上離れる確率は多くとも25%、3σ以上なら11.1%以下」と言えます。正規分布での実際の値（2σ超は約4.6%）に比べると非常に粗い評価ですが、形が分からない状況でも保証が得られる点に価値があります。

大数の法則

n を大きくすると、標本平均 x̄ は母平均 μ に近づいていきます。上の SE = σ/√n が n → ∞ で0になることが、そのままこの法則の中身です（チェビシェフの不等式に SE を入れれば導けます）。これは「値が1点へ収束する」という主張です。

中心極限定理（CLT）

Z = (X̄ - μ) / (σ/√n) → N(0, 1)　　(n → ∞)

母集団の分布が正規でなくても（一様でも、歪んでいても、離散でも）、標本平均を標準化した量の分布は正規分布に近づきます。こちらは「分布の形が正規に収束する」という主張で、大数の法則とは主張の種類が違います。母集団の形を知らなくても正規分布の表が使える、という点で推測統計全体を支えています。

2つの定理の分業大数の法則が「x̄ はどこへ行くか」を答え、中心極限定理が「x̄ はどんな形でばらつくか」を答えます。前者だけでは区間推定はできず、後者があって初めて「±1.96 SE」という具体的な幅が引けます。
CLTの誤解nが大きいと元データ自体が正規になるのではなく、標本平均などの分布が正規に近づきます。強い歪み・外れ値・依存がある場合は「n≥30」の機械的適用を避けます。

4つの基準分布：Z・t・χ²・F

推測統計で使う分布は、実質この4つだけです。すべて標準正規分布から作られていると理解すると、関係が一本につながります。

定義（すべて独立な標準正規 Z から作る）χ²(k) = Z₁² + Z₂² + … + Zk²　　t(ν) = Z / √(V/ν)　（V ∼ χ²(ν)）　　F(ν₁,ν₂) = (V₁/ν₁) / (V₂/ν₂)
  • χ²分布は「標準正規の2乗和」。2乗するので必ず0以上、そして右に裾を引きます。自由度 k は足し合わせた個数で、期待値は k です。分散を扱う場面（分散は2乗の和）で自然に登場します。
  • t分布は「Z の分母 σ を、推定値 S に置き換えたときの分布」。分母自体がばらつくぶん、標準正規より裾が重くなります。自由度 ν が大きくなると S が σ に近づくため、t は N(0,1) に収束します（ν = 30 程度でかなり近い）。左右対称で期待値0。
  • F分布は「2つの χ² を自由度で割って比を取ったもの」。比なので0以上、右に歪みます。分子・分母の自由度2つを持ち、F(ν₁,ν₂) と F(ν₂,ν₁) は別物です。分散の比較（分散比検定・分散分析・回帰の全体検定）に使います。
3つの関係式t(ν)² = F(1, ν)、分母の自由度を無限大にした F(ν, ∞) = χ²(ν)/ν、そして t(∞) = N(0,1)。「2群の t 検定と、2群の分散分析の結論が必ず一致する」のは1つ目の関係式が理由です。
分布中心となる統計量主な用途自由度
標準正規 Z(X̄-μ)/(σ/√n)母分散既知の平均、大標本の比率なし
t(X̄-μ)/(S/√n)正規母集団・母分散未知の平均n-1
χ²(n-1)S²/σ²正規母集団の母分散、度数の検定n-1 など
F(S₁²/σ₁²)/(S₂²/σ₂²)分散比、回帰・分散分析(n₁-1, n₂-1)

どの統計量がどの分布に従うか

正規母集団 N(μ, σ²) から大きさ n の標本を取ったとき、次が成り立ちます（t・χ²・F の「正確な」分布は、この正規性の仮定と結びついています）。

  • (X̄ - μ)/(σ/√n) ∼ N(0,1)：母分散が既知なら Z がそのまま使えます。
  • (n-1)S²/σ² ∼ χ²(n-1)：偏差平方和を σ² で割った量です。自由度が n ではなく n-1 なのは、μ の代わりに x̄ を使ったことで自由に動ける偏差が1つ減るためで、不偏分散で n-1 を割ったのと同じ理由です。
  • (X̄ - μ)/(S/√n) ∼ t(n-1)：上の2つを組み合わせた形になっています。分子は Z、分母は χ²/自由度 の平方根なので、定義どおり t 分布です。σ を s で置き換えたら t を使う、という規則の根拠がここにあります。
  • (S₁²/σ₁²)/(S₂²/σ₂²) ∼ F(n₁-1, n₂-1)：2つの χ² の比なので F。σ₁² = σ₂² を仮定すれば、そのまま s₁²/s₂² が F に従います。

n が大きい場合は中心極限定理により、母集団が正規でなくても平均に関する Z・t は近似的に使えます。一方 χ² と F を使う分散の推測は、正規性からのずれに敏感で、n を増やしても改善しません。分散の検定を軽々に使えないと言われるのはこのためです。

二項分布の正規近似と連続修正

二項分布 X ∼ Bin(n, p) は、n が大きいと計算が煩雑になります。np と n(1-p) がともに十分大きい（目安としてどちらも5以上）とき、中心極限定理により X は正規分布 N(np, np(1-p)) で近似できます。平均と分散を二項分布のものに合わせるだけです。

ただし離散を連続で近似するため、そのままでは境界の扱いがずれます。二項分布では P(X ≤ 3) に X = 3 の確率が丸ごと含まれますが、連続分布では1点の確率は0だからです。そこで、整数 k を「k を中心とする幅1の区間」とみなし、境界を0.5だけ外側にずらします。これが連続修正（半整数補正）です。

連続修正P(X ≤ k) ≈ P(Y ≤ k + 0.5)　　P(X ≥ k) ≈ P(Y ≥ k - 0.5)　　P(X = k) ≈ P(k - 0.5 ≤ Y ≤ k + 0.5)

方向を間違えないコツは「含めたい整数を必ず内側に取り込むように広げる」と考えることです。P(X ≥ 3) なら3を含めたいので 2.5 から、P(X > 3) なら3を除きたいので 3.5 から数えます。n が非常に大きければ0.5のずれは相対的に小さくなりますが、n が中程度のときは無視できません。

標本比率 p̂ = X/n についても同じことで、SE(p̂) = √{p(1-p)/n} を使って p̂ ≈ N(p, p(1-p)/n) とするのが、比率の推定・検定の出発点になります。

上側確率点の読み方表が「P(T ≥ tα)=α」を載せるか、下側累積確率を載せるかを確認。両側5%なら片側2.5%ずつです。
PHASE 3 · ESTIMATION

6. 推定：点ではなく不確かさまで示す

標本から母数を言い当てる作業です。1つの値で答えるのが点推定、幅で答えるのが区間推定。前章の標本分布が、そのまま「幅」の根拠になります。

推定量と推定値

推定量は「標本の関数」という式そのもの（例：X̄ = ΣXᵢ/n）で、標本ごとに値が変わる確率変数です。推定値は、実際のデータを入れて出てきた数値（例：x̄ = 52.3）です。良し悪しを論じられるのは推定量のほうで、性質は次の3つで測ります。

性質定義意味
不偏性E(θ̂) = θ繰り返せば平均的に的中する。系統的なずれ（バイアス）がない
一致性n → ∞ で θ̂ → θデータを増やせば真の値に近づく
有効性Var(θ̂) が小さい不偏なもの同士なら、ばらつきが小さいほど良い
平均二乗誤差（MSE）MSE(θ̂) = E[(θ̂ - θ)²] = Var(θ̂) + {バイアス}²

推定の悪さは「ばらつき」と「偏り」の2成分に分解できる、という重要な式です。不偏（バイアス0）でも分散が大きければ実用にならず、多少偏っても分散が小さいほうが総合的に良い場合もあります。標本平均 X̄ は μ に対して不偏かつ一致、不偏分散 S² は σ² に対して不偏かつ一致です。

点推定量の作り方には、母集団のモーメントと標本のモーメントを対応させるモーメント法と、「観測されたデータが最も起こりやすくなる母数」を選ぶ最尤法があります。二項の p を p̂ = x/n と推定するのは、どちらの方法でも同じ答えになる例です。

区間推定の考え方

点推定は「52.3」と答えますが、これが当たる確率は実質0です。そこで推定の不確かさ（標準誤差）の何倍かを足し引きして、幅で答えます。

信頼区間の共通形推定値 ± 臨界値（分位点） × 標準誤差

作り方の骨格はピボット量（枢軸量）です。たとえば母平均 μ の推定では、(X̄-μ)/(S/√n) が t(n-1) に従うことを利用します。この量が中央95%に入る不等式 -t0.975 ≤ (X̄-μ)/(S/√n) ≤ t0.975 を μ について解くと、そのまま x̄ ± t0.975·s/√n という区間が出てきます。区間推定の公式を丸暗記する必要はなく、「その母数のピボット量は何か」を思い出せば毎回導けます。

95%信頼区間の意味「同じ手順で標本抽出と区間作成を100回繰り返せば、そのうち約95回は真の母数を含む」という手続きの成功率です。すでに計算し終えた1つの区間について「μ がこの中に入る確率は95%」とは、頻度論では言いません。μ は動かない定数で、動くのは区間のほうだからです。

区間の幅は「臨界値 × 標準誤差」の2倍です。したがって幅を決めるのは次の3つ。

  • 信頼係数：1-α を 95% → 99% に上げると臨界値が 1.96 → 2.58 に増え、区間は広がります。確実さと精密さはトレードオフです。
  • 標本サイズ n：SE が 1/√n で縮むため、n を増やすと狭くなります（4倍で半分）。
  • 母集団のばらつき σ：もともとばらつきの大きい対象は、区間も広くなります。

以下で qp は各分布の「下側累積確率がpとなる分位点」、信頼係数は1-α。

必要な標本サイズを逆算する

「誤差の幅（許容誤差）E 以内で母平均を推定したい」なら、E = z1-α/2·σ/√n を n について解きます。

標本サイズの設計n ≥ (z1-α/2 · σ / E)²　　比率なら n ≥ z1-α/2² · p(1-p) / E²

比率の場合、p が未知なら p = 0.5 と置くのが安全です。p(1-p) は p = 0.5 で最大値 0.25 を取るため、最も条件の悪いケースで見積もることになります。95%・許容誤差3%なら n ≈ 1.96²×0.25/0.03² ≈ 1067。世論調査の標本が1000人前後である理由がこれです。母集団の大きさ N はこの式に入っていません——全国調査でも県内調査でも必要数はほぼ同じ、というのが直感に反しつつ重要な点です。

有限母集団補正有限母集団 N から非復元で n 個を単純無作為抽出するときは、標準誤差に √{(N-n)/(N-1)} を掛けます。第4章の超幾何分布に現れた因子と同じものです。抽出率 n/N が小さければ1に近く無視できますが、n/N が大きい（母集団の相当部分を調べた）ときは誤差が実際より小さくなり、区間は狭くなります。

2母集団の区間推定

2群を比べるときは、母数そのものではなく差 μ₁-μ₂ や比 σ₁²/σ₂² を推定します。作り方は1母集団と同じで、「差の推定値 ± 臨界値 × 差の標準誤差」です。差の標準誤差は、独立なら分散が足せることから次のようになります。

平均差の標準誤差（独立2標本）SE(x̄₁-x̄₂) = √(σ₁²/n₁ + σ₂²/n₂)

引き算なのに中身が足し算なのは、両群の不確かさがどちらも差をぼやけさせるからです（Var(X-Y) = Var(X)+Var(Y)）。母分散が未知のときは、等分散を仮定するかどうかで2通りに分かれます。

プールした分散（等分散を仮定する場合）sp² = {(n₁-1)s₁² + (n₂-1)s₂²} / (n₁+n₂-2)

これは2群の不偏分散を自由度で重み付けした加重平均です。「どちらの群も同じ σ² を持つ」という仮定のもと、両群のデータを合わせて σ² を1つ推定するので、自由度も n₁-1 と n₂-1 を足した n₁+n₂-2 になります。標本サイズが大きい群の情報が強く反映される点に注目してください。

等分散が疑わしいときはウェルチ法を使い、各群の分散を別々に使った √(s₁²/n₁ + s₂²/n₂) を標準誤差とし、自由度は近似式で求めます。分散が大きく違い n も違う場面ではプール法の誤差が大きくなるため、実務では最初からウェルチ法を既定とすることが多くなっています。

PHASE 3 · HYPOTHESIS TESTING

7. 仮説検定：珍しさを基準に判断する

「偶然でもこの程度は起こるのか、それとも偶然では説明しにくいのか」を、確率で線引きする手続きです。背理法に似た構造を持っています。

手順と、その各段階の意味

  1. 仮説を立てる。否定したい主張を帰無仮説 H₀（「差がない」「μ = μ₀」など等号を含む形）、示したい主張を対立仮説 H₁ とします。H₀ を等号にするのは、「その値を仮定すれば検定統計量の分布が1つに決まる」からです。分布が決まらなければ確率計算ができません。仮説はデータを見る前に立てます。
  2. 有意水準 α を決める。「これ以下の確率なら偶然とは考えない」という基準（通常5%や1%）。これも事前に決めます。
  3. 検定統計量を選ぶ。H₀ が正しいときの分布が分かっている量を使います。多くは (推定値 - H₀の値)/標準誤差 の形で、H₀ からの「ずれの大きさを標準誤差何個ぶんで測ったもの」です。
  4. p値を求める。H₀ が正しいと仮定したとき、観測された統計量と同じかそれ以上に H₁ 方向へ極端な値が出る確率です。あるいは、あらかじめ棄却域（分布の端 α ぶんの領域）を作り、統計量がそこに落ちるかを見ても同じ結論になります。
  5. 判断する。p ≤ α なら H₀ を棄却し「有意差あり」。p > α なら「棄却できない」——採択・証明ではありません。ここは背理法と違い、「矛盾が出なかった＝仮定が正しい」とは言えない点が決定的です。
  6. 解釈する。有意かどうかだけでなく、効果の大きさ（差の推定値と信頼区間）、前提の妥当性、実質的な意味を併せて述べます。

有意水準 α は、そのまま「第1種の過誤を犯す確率の上限」です。α = 0.05 とは「H₀ が正しいのに誤って棄却してしまう危険を5%まで許す」という宣言にほかなりません。検出力 1-β は「本当に差があるとき、それを検出できる確率」で、実験計画の中心的な指標です。

n を固定したまま α を小さくすると（例：5% → 1%）、棄却域が狭くなるので第1種の過誤は減りますが、そのぶん見逃しが増えて β は大きくなります。α と β は同時には減らせず、両方を下げる唯一の正攻法は n を増やすことです。α を厳しくするのは「間違って効果ありと言う損害」が大きい場面（新薬の承認など）、β を重視するのは「見逃しの損害」が大きい場面（スクリーニング検査など）です。

効果量：有意性とは別の軸

n を十分大きくすれば、実質的にどうでもよい小さな差でも p は小さくなります。逆に n が小さければ、大きな差でも有意になりません。したがって「有意である」は「差が大きい」を意味しません。差の大きさそのものは、平均差や、標準偏差を単位として測った効果量で報告します。

効果量の例（2群の平均差）d = (x̄₁ - x̄₂) / sp

「差は標準偏差何個ぶんか」を表すので、単位にも n にも依存しません。検定結果は必ず、効果量か信頼区間と組にして読みます。

p値の誤解p値は「H₀が正しい確率」でも「偶然で結果が出た確率」でもありません。H₀を仮定したときに、観測値以上に極端な統計量が出る確率です。p>0.05は同等性の証明ではありません。

PHASE 3 · CATEGORICAL DATA

8. χ²検定：観測度数と期待度数を比べる

扱うデータが「人数・件数」というカテゴリの度数のとき使います。平均や分散ではなく、表の数字そのものを比較対象にする点が特徴です。

χ²統計量χ² = Σ (O - E)² / E　　（O：観測度数、E：H₀の下での期待度数）

式の意味を分解します。O - E は「予想からのずれ」、2乗するのは符号を消して大きさだけを見るため（そのまま足すと打ち消し合って0になります）。E で割るのが最も重要な部分で、これは「ずれを期待度数に対する相対的な大きさに直す」正規化です。期待度数1000のセルでの10のずれと、期待度数10のセルでの10のずれでは、後者のほうがはるかに深刻——それを式に反映させています。ずれの大きさを測る量なので χ² は常に0以上、棄却域は上側だけです。

適合度検定：理論比に合っているか

1つの質的変数の分布が、指定された比率どおりかを調べます。期待度数は E = n × (仮定した比率) で計算します。

数値例サイコロを60回振り、1〜6が 8, 12, 7, 15, 9, 9 回出た。H₀「各目が等確率」の下で期待度数はすべて 60 × 1/6 = 10。
χ² = (8-10)²/10 + (12-10)²/10 + (7-10)²/10 + (15-10)²/10 + (9-10)²/10 + (9-10)²/10 = (4+4+9+25+1+1)/10 = 4.4。
自由度は 6-1 = 5、χ²(5) の上側5%点は 11.07 なので棄却できず、「歪んだサイコロとは言えない」となります。
適合度検定の自由度df = k - 1 - m　　（k：カテゴリ数、m：データから推定した母数の個数）

k-1 なのは、度数の合計が n に固定されているため、最後の1セルは他が決まれば自動的に決まるからです。さらに、正規分布やポアソン分布への当てはまりを見る場合のように母数をデータから推定したときは、その個数だけ自由度が減ります（ポアソンで λ を推定したなら m = 1）。

独立性検定：2つの質的変数に関連があるか

クロス集計表（分割表）で、行の変数と列の変数が独立かを調べます。ここでの期待度数は、確率の独立の定義から導かれます。独立なら P(行i かつ 列j) = P(行i) × P(列j) なので、

期待度数Eij = n × (行i合計/n) × (列j合計/n) = (行i合計 × 列j合計) / n

「その行の割合が、どの列でも同じ」という状態を数字にしたものです。実測がここから大きくずれるほど χ² が大きくなり、独立という仮定が疑わしくなります。

独立性検定の自由度df = (r - 1)(c - 1)

行合計と列合計が固定されているため、r×c 個のセルのうち自由に決められるのは左上の (r-1)×(c-1) 個だけで、残りは引き算で決まります。2×2 表なら自由度は1です。

棄却したあと何を言うかχ² 検定が示すのは「関連がある」までで、どのセルが効いたか、関連の向きや強さは分かりません。各セルの標準化残差 (O-E)/√E を見て寄与の大きいセルを特定したり、行ごとの割合を比べて向きを述べたりする追加の作業が要ります。また χ² の大きさは n に比例して大きくなるので、χ² の値そのものを関連の強さとして読んではいけません（クラメールのVなどの指標を使います）。
小さい期待度数χ²近似が悪くなります。カテゴリ統合が科学的に妥当か、2×2ならFisherの正確確率検定など別手法が必要かを検討します。
PHASE 4 · LINEAR MODELS

9. 回帰分析：他の変数を固定した効果を読む

単回帰の説明変数を複数に増やしたものが重回帰です。増やす目的は予測精度だけでなく、交絡変数を統計的に調整することにあります。

重回帰モデルYᵢ = β₀ + β₁Xᵢ₁ + β₂Xᵢ₂ + … + βpXᵢp + εᵢ　　εᵢ ∼ 独立に N(0, σ²)

モデルは「構造部分（説明変数の1次式）＋ 誤差項 ε」という形をしています。誤差項に置く仮定——独立・平均0・等分散・正規——が、後の t 検定や F 検定の根拠になります。「線形モデル」の線形とは、x について直線という意味ではなく係数 β について1次という意味です。だから x² や log x を説明変数に入れても、それは依然として線形モデルです。

偏回帰係数の読み方

βⱼ は「他の説明変数の値を一定に保ったまま Xⱼ を1単位増やしたときの、Y の平均的な変化量」です。この「他を一定に保つ」がまさに調整であり、単回帰の係数と重回帰の係数が食い違う理由でもあります。たとえば「広さ」だけで家賃を回帰すると、広い家ほど駅から遠い傾向があるぶんまで係数に混ざりますが、「駅からの距離」を同時に入れれば、距離が同じ物件どうしを比べた効果に近づきます。

係数は単位に依存するので、大きさの比較には使えません（年収を「円」から「万円」に変えれば係数は1万分の1になります）。影響の相対的な大きさを比べたいときは、変数を標準化した標準化偏回帰係数を使います。

2種類の検定：個別のt検定と全体のF検定

個別の係数（t検定）t = bⱼ / SE(bⱼ)　　H₀: βⱼ = 0　　自由度 n - p - 1

「他の変数を調整したうえで、Xⱼ には説明力があるか」を見ます。分母の SE(bⱼ) は、残差分散が大きいほど、また Xⱼ が他の説明変数と強く相関しているほど大きくなります。自由度が n-p-1 なのは、β₀ を含む p+1 個の母数を推定したぶん減るからです。

モデル全体（F検定）F = (SSR / p) / {SSE / (n-p-1)} = MSR / MSE　　H₀: β₁ = β₂ = … = βp = 0

「説明変数を全部まとめて、切片だけのモデルより説明力が上がっているか」を見ます。分子が「説明できた変動の1自由度あたりの大きさ」、分母が「説明できなかった変動の1自由度あたりの大きさ」なので、比が大きいほどモデルは有効です。全体のF が有意でも個別のt がどれも有意でないことがあり、その典型的な原因が次の多重共線性です。

決定係数と自由度調整済み決定係数

R² には「説明変数を追加すると、無意味な変数でも決して下がらない」という欠点があります。変数を増やせば最小二乗法はより細かくデータに合わせられるので、SSE は必ず減るからです。これを罰するのが自由度調整済み決定係数です。

自由度調整済み決定係数R̄² = 1 - {SSE/(n-p-1)} / {SST/(n-1)}

平方和そのものではなく、自由度で割った平均平方の比を使うのがポイントです。変数を1つ増やすと SSE は減りますが、同時に分母の自由度 n-p-1 も減ります。減り方が小さければ SSE/(n-p-1) はむしろ増え、R̄² は下がります。つまり「増やした変数が、その1自由度に見合う説明をしたか」を判定しているわけです。R̄² は負の値も取り得ます。

多重共線性

説明変数どうしが強く相関している状態です。「他を一定に保ったときの効果」を推定したいのに、実際のデータでは2変数がほぼ一緒に動いていて分離できない、という状況で、係数の推定が不安定になります。

分散拡大要因VIFj = 1 / (1 - Rj²)　　（Rj²：Xⱼ を他の説明変数で回帰したときの決定係数）

Xⱼ が他の変数でよく説明できてしまう（Rj² が1に近い）ほど VIF は大きくなり、SE(bⱼ) は √VIF 倍に膨らみます。Rj² = 0.9 なら VIF = 10 で標準誤差は約3.2倍。目安として VIF が10を超えたら要注意です。症状は「符号が理論と逆になる」「標準誤差が大きく個別のt が有意にならない」「データを少し変えると係数が大きく動く」のに、モデル全体の F と R² は高いまま、という組み合わせで現れます。対処は変数の削除、合成（主成分など）、中心化などです。

ダミー変数：質的変数を回帰に入れる

「男/女」「A社/B社/C社」のようなカテゴリは、0/1 のダミー変数に直して投入します。k カテゴリなら作るのはk-1 個で、残した1つが基準カテゴリ（参照群）になります。

  • 切片＝基準カテゴリでの平均的な水準。
  • ダミーの係数＝そのカテゴリと基準カテゴリとの差。「地域Bの係数が +3.2」なら、基準地域より平均3.2高いという意味で、絶対値そのものではありません。
  • 基準をどれにするかで係数の値も解釈も変わります。有意性の結論も基準次第で変わり得ます。
ダミー変数トラップ切片と k 個すべてのダミーを同時に入れると、ダミーの合計が常に1（＝切片の列と一致）になり、完全な多重共線性が生じて解が一意に定まりません。だから必ず1つ落とします。

説明変数どうしの交互作用（例：X₁ × X₂ の積を投入）を入れると、「X₂ の水準によって X₁ の効果が変わる」状況を表現できます。この場合、X₁ の主効果の係数は「X₂ = 0 のときの効果」に読み替わる点に注意します。

係数の有意性 ≠ 因果効果交絡、逆因果、選択バイアス、測定誤差があれば、調整済みでも因果とは限りません。また補外（観測範囲外の予測）は危険です。

PHASE 4 · ANOVA

10. 分散分析：3群以上の平均差を一度に検定

「平均の差を検定するのに、なぜ分散を分析するのか」——この問いに答えられれば、この章は理解できています。

H₀: μ₁ = μ₂ = … = μk（すべての群の母平均が等しい）、H₁: 少なくとも1組は異なる。判断の材料は、群の平均どうしのばらつきと群の内部でのばらつきの比です。群平均が多少バラついていても、もともと個体差が大きければ偶然の範囲。逆に群内が揃っているのに群平均が離れていれば、処理の効果を疑う——この直感を式にしたものが分散分析です。

平方和の分解SST = SSB + SSE　　（全体の変動 ＝ 群間変動 ＋ 群内変動）

各データの全体平均からのずれを、(xᵢⱼ - x̄) = (x̄ⱼ - x̄) + (xᵢⱼ - x̄ⱼ) と、「群平均が全体平均からどれだけずれているか」と「個体が自分の群平均からどれだけずれているか」に分けて2乗和を取ると、交差項が消えてこの分解が得られます。

F比F = MSB / MSE = {SSB/(k-1)} / {SSE/(N-k)}

平方和はデータ数が増えれば増えるので、そのままでは比べられません。それぞれを自由度で割った平均平方（1自由度あたりの変動）に直してから比を取ります。自由度は、群間が「k個の群平均のうち自由に動けるのは k-1 個」、群内が「N個のデータから k 個の群平均を引いた N-k」です。

変動源平方和自由度平均平方
群間（処理）SSB=Σnⱼ(x̄ⱼ-x̄)²k-1MSB=SSB/(k-1)
群内（誤差）SSE=ΣΣ(xᵢⱼ-x̄ⱼ)²N-kMSE=SSE/(N-k)
全体SST=ΣΣ(xᵢⱼ-x̄)²N-1-

なぜ F 比で平均の差が判定できるのか

鍵は2つの平均平方の期待値にあります。

E(MSE) = σ²　　E(MSB) = σ² + {Σ nⱼ(μⱼ - μ)²} / (k-1)

MSE は群平均からのずれだけを使うので、群平均が違っていても影響を受けず、常に誤差分散 σ² を推定します。一方 MSB は、H₀ が正しければ（すべての μⱼ が等しく第2項が0になり）同じく σ² を推定しますが、群平均に差があれば第2項のぶんだけ大きくなります。

つまり H₀ の下では F = MSB/MSE ≈ 1、差があれば分子だけが膨らんで F は1より大きくなる。だから「平均の差」の検定でありながら、統計量は分散の比になり、棄却域は上側だけになるのです。F が1より十分大きいかを F(k-1, N-k) 分布で判定します。

前提は3つ：各群の観測が独立、各群が正規分布に従う、各群の分散が等しい（等分散性）。等分散性は MSE を「共通の σ²」として1つにプールするために必要で、独立2標本のプールt検定と同じ発想です。実際、k = 2 のとき分散分析のF は 2標本t検定の t の2乗に一致し、結論も必ず一致します（前章の t(ν)² = F(1,ν) の関係）。

効果の大きさ（寄与率）η² = SSB / SST

「全変動のうち、群の違いで説明できる割合」で、回帰の R² と同じ考え方です。F の有意性は n に依存するため、効果の大きさはこちらで見ます。

棄却しても「どの群か」は分からない分散分析が言えるのは「少なくとも1つの群の平均が他と異なる」までです。どの組み合わせに差があるかは、次の多重比較で調べます。
回帰との統一一元配置ANOVAは、群をk-1個のダミー変数で表した回帰モデルと同じ線形モデルとして扱えます。ANOVAのF検定は、そのダミー係数がすべて0かを検定しています。

多重比較：なぜ t 検定を繰り返してはいけないか

3群なら組み合わせは3通り。それぞれに有意水準5%の t 検定を行うと、各回は5%でも、全体としてどこかで誤って棄却する確率（family-wise error rate）は跳ね上がります。

少なくとも1回誤る確率（独立に近い場合の目安）1 - (1 - α)m　　（m：検定の回数）

m = 3 なら 1 - 0.95³ ≈ 14.3%、群が5つ（m = 10 通り）なら 1 - 0.95¹⁰ ≈ 40%。「差がないのに差を見つけてしまう」危険が制御できなくなります。分散分析はまず1回の検定で全体を判定し、そのあと家族単位の誤差率を調整した多重比較法（すべての対を比べるならテューキー法、対照群との比較だけならダネット法、汎用的に使えるが保守的なボンフェローニ法＝有意水準を m で割る方法）で、どの対に差があるかを特定します。

検定検定統計量 = (推定値 - H₀の値) / H₀の下での標準誤差
推定信頼区間 = 推定値 ± 分位点 × 推定した標準誤差

両者はコインの裏表です。検定は「H₀ の値を基準にして、推定値がどれだけ離れているか」を測り、区間推定は「推定値を基準にして、どの範囲の母数ならこのデータと矛盾しないか」を示します。だから両側α検定で θ₀ を棄却することと信頼係数1-αの区間が θ₀ を含まないことは、同じ前提・同じ手法なら一致します。
